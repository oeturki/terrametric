Sample: Live readings update automatically. Edit thresholds and intervals, then hit Save. Server threshold alerts use the sample that receives the reading (recording session or TM_BRIDGE_PLANT_ID); if that id differs from the sample selected here, alert bands will not match this form. Ventilation (auto): during recording only, the Pi is driven from Desired min/max on temperature & humidity. Tolerance (warn low/high on temperature, humidity, and light only) feeds threshold alerts / chart overlays — not height. Changing tolerance does not start or stop automatic ventilation. While you are recording, hitting Save here re-checks desired bands against the latest reading and can turn ventilation off without waiting for the next packet.

Capture on Motion
Capture on Warning
Turn off Capture on Motion only if you do not want a Gallery screenshot when motion is detected (PIR low→high; rate-limited; Pi must be reachable). On by default. Desired min/max on temperature, humidity, and light: Gallery snapshots save automatically when a reading leaves that band (like the height milestone; Pi must be reachable). Capture on Warning additionally enables snapshots when readings leave tolerance (soft warn) bands — those can fire even while still inside desired min/max. Samples saved earlier may still have Capture on Warning off until you Save or Reset to Defaults.

Sensor telemetry
Only one sample can record chamber data at a time. Register your Arduino below (match the Bluetooth name from your sketch, e.g. Group14), choose it, then start — incoming readings are tagged until you stop. Save the sample first so it has a server ID.

If Stream dummy data is off, the scenario is saved on the session record but does not generate points; charts then show only real ingest (and any old backfill rows for this sample).

View Data graphs show every reading for the sample and time range you choose there (older backfill, past sessions, and the current run mix together). Use Clear telemetry to reset, or on Graphs check This recording only while a session is active for that sample.
